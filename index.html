The platform

从告警，走向防御闭环

安全不只是发现异常。还需要解释风险、约束操作、验证结果，并留下可供复盘的证据。

◈

风险研判

将安全事件整理成结构化上下文，辅助理解风险等级、判断依据与不确定性。

⌘

策略与权限

强调最小权限与明确授权，避免把模型输出直接当成可信系统命令。

✓

验证与审计

区分建议、批准、执行与验证状态，避免把动作完成误认为风险已消除。

事件接入→风险研判→策略检查→授权 / 模拟→结果验证→审计复盘
Security principles

安全边界不是附加项

这些原则应贯穿架构、实现、测试和产品体验。

零信任默认不信任，逐项验证请求与上下文。
最小权限只授予完成任务所需的最低访问能力。
人工审批高影响操作保持明确授权和人的控制。
结果可验证验证安全目标是否达成，而不只看执行状态。
Project status

透明地建设，谨慎地承诺

KISIV AI 当前处于早期 MVP / 持续开发阶段。项目已包含基础 FastAPI + SQLite 应用、安全事件录入与查询、初步规则研判、默认 dry-run 模拟响应、审计记录与基础测试。

重要说明：当前不是生产级安全产品，不会自动封禁真实 IP、修改防火墙或执行系统命令。跨平台实时连接、通用 Agent 权限拦截和真实自动化处置均属于后续方向。请以仓库文档与实际测试结果为准。
